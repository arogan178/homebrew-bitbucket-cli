# homebrew-bitbucket-cli

Homebrew tap for [`bt`](https://github.com/arogan178/bitbucket-cli), a `gh`-style CLI for Bitbucket Cloud and Data Center.

## Install

```sh
brew install arogan178/bitbucket-cli/bt
```

## Upgrade

```sh
brew update && brew upgrade bt
```

## About

`bt.rb` is generated by GoReleaser on each `bt` release. Don't edit it by hand. Report issues with `bt` itself in the [main repository](https://github.com/arogan178/bitbucket-cli/issues).
